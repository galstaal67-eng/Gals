# 🏔️ אתר הטיול — סקוטלנד

אתר סטטי לתכנון וניהול הטיול, 19/09/2026 – 02/10/2026 (14 ימים).
עברית מלאה (RTL), מותאם לניידים, ללא שרת וללא תהליך בנייה.

המסלול: 3 ימים באדינבורו → רכבת על ה-West Highland Line אל תחילת השביל →
**שלושה ימי הליכה רצופים על ה-West Highland Way** — שלושת המקטעים האחרונים שלו,
בסיום הרשמי בפורט וויליאם → מעבורת לאי סקאי → 3 ימים בסקאי → לילה בקיירנגורמס →
פרתשייר → יומיים אחרונים באדינבורו וטיסה הביתה.
13 לילות בתשעה מקטעים, 895 ק"מ ברכב ו-57 ק"מ ברגל.

**שבעת הימים הראשונים הם בלי רכב בכלל.** ל-West Highland Line יש תחנה בברידג' אוף אורקי,
והיא יושבת ממש על ה-West Highland Way — בדיוק בנקודה שבה מתחיל יום ההליכה הראשון. לכן
יום 4 הוא רכבת מאדינבורו דרך גלזגו, לנים שם, וביום 5 יוצאים מפתח המלון. משם הולכים
קדימה בלבד — ברידג' אוף אורקי → קינגסהאוס → קינלוכליבן → פורט וויליאם — וישנים בכל לילה
בנקודה שאליה הגיעו ברגל. אפס אוטובוסים, אפס מוניות, אפס חניה; שירות העברת מזוודות
מעביר את התיקים. הרכב נאסף רק ביום 8 בפורט וויליאם ומוחזר ב-EDI ביום 12 — חמישה ימי
השכרה במקום תשעה, בתמורה לחיוב השכרה חד-כיוונית.

תשעת הלילות שבמסלול נבדקו מול זמינות אמיתית (~£1,380 לזוג, בלי Kings House
ו-Bridge of Orchy Hotel שמוזמנים ישירות אצלם); לילות אדינבורו נשארים לבחירת המשתמש.

הטיסות **טעונות שינוי** מול לופטהנזה: TLV 16:30 → EDI 22:45 ב-19/9,
ו-EDI 06:10 → TLV 15:25 ב-2/10. ההזמנה הקיימת היא ל-16/9–29/9, והתעריף Economy Light
לרוב אינו ניתן לשינוי — צריך לברר את העלות לפני שסוגרים את שאר ההזמנות.

## ייצוא ל-Google Maps

מתחת למפה יש שתי דרכים להגיע ל-Google Maps:

- **🧭 ניווט ביום הנבחר** — נפתח רק אחרי שבוחרים יום מהצ'יפים, ופותח את
  אותו יום כמסלול ניווט. הכפתור מושבת במצב "כל הימים" בכוונה: ה-URL API
  של Google Maps מוגבל ל-9 נקודות ביניים, ואין דרך לדחוס לתוכו את כל הטיול.
- **⬇️ הורדת כל המסלול** — מוריד `scotland-2026-route.kml` עם כל נקודות
  העצירה וכל קווי המסלול, **בלי מקטעי הטיסה**. מייבאים אותו ל-
  [Google My Maps](https://www.google.com/mymaps): מפה חדשה → ייבוא → הקובץ.
  אותו קובץ נפתח גם ב-Google Earth וברוב אפליקציות הניווט.

הקיבוץ בקובץ הוא **לפי אזור ולא לפי יום** — חמש תיקיות, כי My Maps מגביל
ל-10 שכבות למפה ו-14 תיקיות היו חורגות. מספר היום נשאר בשם של כל נקודה
("‎7 · Steall Falls"), כך שלא מאבדים את הסדר.

נתב"ג ופרנקפורט מסוננים לפי תיבה תוחמת של בריטניה; נמל התעופה של אדינבורו
נשאר, כי שם אוספים ומחזירים את הרכב.

## שלושת ימי ההליכה

הליבה של החלק ההררי: שלושת המקטעים האחרונים של ה-**West Highland Way**,
ברצף ובסדר הנכון, עד נקודת הסיום הרשמית שלו בפורט וויליאם.

| יום | מקטע | אורך | זמן | עלייה |
| --- | --- | --- | --- | --- |
| 5 (20/9) | Bridge of Orchy → Kingshouse, לרוחב שממת ראנוך | 19 ק"מ | 5.5–7 ש' | ~400 מ' |
| 6 (21/9) | Kingshouse → Kinlochleven דרך מדרגות השטן | 14 ק"מ | 4.5–5.5 ש' | ~350 מ' (פסגה 548 מ') |
| 7 (22/9) | Kinlochleven → Fort William דרך הלאיריג מור | 24 ק"מ | 6.5–7.5 ש' | ~350 מ' |

סה"כ 57 ק"מ ו-~1,100 מ' עלייה מצטברת בשלושה ימים רצופים.

הלוגיסטיקה של הרכב, בדיוק כפי שביקשתם — הרכב תמיד מחכה בקצה:

- **יום 5** — נוסעים 20 דקות מבליצ'וליש לקינגסהאוס ומשאירים שם את הרכב.
  Citylink 914/915/916 דרומה לברידג' אוף אורקי, והולכים צפונה בחזרה אליו.
- **יום 6** — בבוקר נוסעים עם כל הציוד לקינלוכליבן ומשאירים שם את הרכב,
  חוזרים לקינגסהאוס במונית מוזמנת מראש (~£35–45) או ב-Stagecoach 44 + Citylink,
  והולכים אל הרכב. הלינה בקינלוכליבן.
- **יום 7** — בבוקר נוסעים לפורט וויליאם ומשאירים שם את הרכב והמזוודות,
  חוזרים לקינלוכליבן ב-Stagecoach 44 (~40 דק', הקו הכי תדיר מהשלושה),
  והולכים אל הרכב ואל המלון.

שלושת המקטעים על ציר A82 ולכן משורתים בתחבורה ציבורית — מה שלא נכון לרוב
המסלולים היפים בסקוטלנד, וזה מה שמאפשר את התרגיל הזה בכלל.

> ⚠️ יום 7 הוא היחיד שאין ממנו יציאה באמצע: אחרי 5 ק"מ אין כביש, אין יישוב
> ואין קליטה עד גלן נוויס. מחליטים בבוקר. החלופה, אם זה נראה יותר מדי:
> מפל סטיל בגלן נוויס (3 ק"מ) ורכבל Nevis Range.

## לשונית תכנון העלויות

אומדן שנעשה **לפני** הטיול, לזוג אחד (שני מבוגרים, חדר זוגי):

- ארבע קבוצות — טיסות, מלונות, רכב, ונסיעות/כניסות/חניונים. שלוש הראשונות
  הן הליבה; הרביעית ניתנת לכיבוי בתיבת סימון.
- כל שורה היא טווח (מ־/עד) במטבע שלה, **ניתן לעריכה** — מחליפים אומדן במחיר
  אמיתי ברגע שמזמינים, והסיכומים מתעדכנים מיד.
- סיכומים: סה"כ לזוג, לאדם, ללילה וליום, כולל הטווח המלא.
- **אוכל ושתייה אינם כלולים** בכוונה. אומדן נפרד לאלה נמצא בלשונית "מידע וציוד".
- **העריכות מסונכרנות בין המכשירים.** מחיר שמעדכנים בטלפון אחרי שסוגרים
  הזמנה מופיע גם אצל בן/בת הזוג. שדה שמרוקנים חוזר לאומדן המקורי בכל
  המכשירים. תיבת "כלול כניסות" נשארת מקומית — היא תצוגה, לא נתון.

## לשונית ההוצאות בפועל

לניהול ההוצאות **במהלך** הטיול. משחזרת את הלוגיקה של גיליון ההוצאות מהטיול הקודם:

- **הזנה במטבע המקורי** — £ / € / $ / ₪, עם המרה אוטומטית לשקל.
- **שערי המרה ניתנים לעריכה** — שינוי שער מחשב מחדש את כל הטבלה מיידית,
  ומשותפים עם לשונית תכנון העלויות.
- **11 סעיפי הוצאה** — אוכל, דלק, לינה, טיסות, נסיעות, אטרקציות, חניה,
  קניות, בילויים, רפואה, אחר.
- **קיזוז בין זוגות** — חלוקה שוויונית לנפש, ואז חישוב ההעברה הנדרשת
  ("זוג 2 מעביר X ₪ לזוג 1"). האלגוריתם חמדני ותומך גם ביותר משני זוגות.
- **ניתוחים** — חלוקה לסעיפים, הוצאה לפי אדם, והוצאה יומית לאורך הטיול.
- **תקציב יעד** — אופציונלי, עם מד ניצול שמשנה צבע בחריגה.
- **ייצוא/ייבוא CSV** — עם BOM כדי ש-Excel יציג עברית תקינה. הייבוא מקבל
  תאריכים בפורמט `yyyy-mm-dd` או `dd/mm/yyyy`.

### אחסון וסנכרון

האתר עובד בשני מצבים, והמעבר ביניהם אוטומטי:

| | מסונכרן ☁️ | מקומי 📱 |
| --- | --- | --- |
| מתי | הפונקציות של Netlify זמינות | פתיחה מהדיסק, פריסה סטטית, או תקלת רשת |
| הוצאות, מטיילים, שערים, תכנון עלויות | Postgres משותף לכל המכשירים | `localStorage` בלבד |
| ציוד, ערכת צבעים, תיבת "כלול כניסות" | `localStorage` בכל מכשיר | `localStorage` בכל מכשיר |

הזיהוי הוא ניסיון קריאה אחד ל-`/api/state` בטעינה. כישלון אינו שגיאה — הוא
פשוט אומר "מצב מקומי", והאתר ממשיך לעבוד במלואו. מחוון בראש לשונית ההוצאות
מציג תמיד באיזה מצב אתם.

`localStorage` (מפתח `scotland2026:v1`) משמש גם במצב מסונכרן כמטמון, כך
שהדף מרונדר מיד ולא ממתין לשרת.

**מעבר ממצב מקומי לענן:** אם יש הוצאות ששמורות רק במכשיר והשרת ריק, האתר
מציע להעלות אותן בלחיצה אחת במקום למחוק אותן בשקט.

### הסכמה

```
expenses        id, spent_on, amount, currency, category, payer, note,
                created_at, deleted_at        ← מחיקה רכה
travellers      name, couple_group, sort_order
fx_rates        currency, ils_per_unit, updated_at
cost_overrides  item_key ("hotels:3"), low_amount, high_amount, updated_at
```

מחיקת הוצאה היא מחיקה רכה (`deleted_at`), כדי שהקשה מוטעית בטלפון לא תאבד
רשומה לתמיד. השאילתות מסננות `deleted_at IS NULL`.

### ה-API

| שיטה | נתיב | תיאור |
| --- | --- | --- |
| `GET` | `/api/state` | כל המצב המשותף בבקשה אחת |
| `POST` | `/api/expenses` | הוספת הוצאה; השרת מקצה UUID |
| `POST` | `/api/expenses/bulk` | אצווה — ייבוא CSV והעלאת נתונים מקומיים |
| `DELETE` | `/api/expenses/:id` | מחיקה רכה |
| `DELETE` | `/api/expenses` | מחיקה רכה של הכול |
| `PUT` | `/api/settings` | החלפת רשימת המטיילים ו/או השערים |
| `PUT` | `/api/cost` | עדכון שורות בתכנון העלויות; `null` מוחק שורה |

כל קלט מאומת בשרת: סכום חיובי, מטבע מרשימה סגורה, תאריך `yyyy-mm-dd`,
ואורכי שדות. אצווה עם רשומה פסולה נדחית **כולה** — אצווה חלקית גרועה יותר
מאצווה שנדחתה. עדכון המטיילים רץ בטרנזקציה, כדי שבקשה שנכשלת באמצע לא
תשאיר רשימה חלקית.

`/api/cost` הוא היחיד שמעדכן נקודתית ולא בהחלפה מלאה, וזה מכוון: שני בני
הזוג עורכים שורות שונות באותו זמן (אחד סוגר מלון, השני רכב), והחלפה מלאה
מתמונת מצב ישנה הייתה מוחקת את העריכה של השני. `low > high` **אינו** נדחה —
המשתמש מקליד שדה אחד בכל פעם, ובאמצע ההקלדה הטווח הפוך לרגע.

> ⚠️ **אין אימות משתמשים.** כל מי שמגיע לכתובת יכול לקרוא ולערוך את ההוצאות.
> זו הייתה החלטה מודעת. להוספת קוד טיול משותף בהמשך צריך לבדוק משתנה סביבה
> אחד ב-`netlify/lib/shared.mts` ולהוסיף מסך כניסה — שינוי קטן.

## מבנה

```
trip/
├── index.html                  # שלד הדף וכל הלשוניות
├── package.json                # תלויות הפונקציות (@netlify/database, @netlify/functions)
├── assets/
│   ├── css/styles.css          # עיצוב, כולל מצב בהיר והדפסה
│   ├── js/
│   │   ├── data.js             # כל תוכן הטיול — ימים, נקודות, טיפים, המלצות, עלויות
│   │   ├── api.js              # שכבת הגישה לשרת + זיהוי מצב מקומי
│   │   └── app.js              # רינדור, מפה, תכנון עלויות, הוצאות וקיזוז
│   └── vendor/leaflet/         # Leaflet 1.9.4 (BSD-2-Clause), מקומי
├── netlify/
│   ├── lib/shared.mts          # אימות קלט ועזרי תגובה
│   ├── functions/              # כל קובץ כאן נפרס כפונקציה — קוד משותף שייך ל-lib/
│   │   ├── state.mts           # GET /api/state
│   │   ├── expenses.mts        # POST/DELETE /api/expenses
│   │   ├── settings.mts        # PUT /api/settings
│   │   └── cost.mts            # PUT /api/cost
│   └── database/migrations/    # SQL שרץ אוטומטית בכל פריסה
└── README.md
```

`netlify.toml` יושב בשורש המאגר ומגדיר `base = "trip"`, ולכן כל מה שקשור
לטיול — כולל `package.json` והפונקציות — נמצא כאן ולא בשורש מאגר ה-SOX.

### עריכת המסלול

כל התוכן יושב ב-`assets/js/data.js` במבנה אחד (`TRIP`). כדי לשנות יום —
עורכים את האובייקט שלו; אין צורך לגעת ב-HTML או ב-JS. שדות מרכזיים לכל יום:

```js
{
  n: 5, date: "2026-09-20", dow: "ראשון",
  title: "...", region: "גלנקו",     // region מזין את גרף הק"מ ואת הצ'יפ שמעל המפה
  mapLabel: "הליכה 1",                // אופציונלי — גובר על region בצ'יפ בלבד
  mode: "hike",                       // flight | drive | hike | city
  drive: { km: 0, hours: 0, note: "..." },   // גם בימי הליכה, אם יש הסעת רכב
  hotel: { name: "...", area: "...", lat, lng, booked: true },
  plan:  [{ time: "09:00", text: "..." }],
  tips:  ["..."],
  points: [{ name: "...", lat, lng, type: "hike" }],  // type קובע את האייקון
  path:  [[lat, lng], ...],           // הקו על המפה
  pathMode: "hike"
}
```

## התאמה לניידים

נבדק ב-Chromium ברוחב 390px בכל הלשוניות:

- אפס גלילה אופקית. פריטי grid מקבלים `min-width: 0` מפורש — בלעדיו תוכן רחב
  (טבלה עם `min-width`) מנפח את כל הרשת ומוציא את הדף מהמסך.
- **טבלאות נפרסות לכרטיסים** מתחת ל-640px במקום גלילה הצידה. כותרת כל תא
  מגיעה מ-`data-label` דרך `::before`.
- אזורי מגע של 44px לכל הכפתורים, הלשוניות והצ'יפים תחת `@media (pointer: coarse)`.
- שדות קלט ב-16px בדיוק על מסכי מגע — מתחת לזה ספארי מזנק זום בעת מיקוד.
- **המפה נעולה עד להקשה** במסכי מגע. בלי זה אצבע על המפה חוטפת את גלילת הדף
  ואי אפשר לעבור אותה.
- טופס בעמודה אחת, סרגל לשוניות שגולל את הנבחרת לתצוגה, ו-`theme-color`
  לסרגל הדפדפן.

## פיתוח מקומי

```bash
cd trip
npm install
npx netlify dev      # מקים גם Postgres מקומי אוטומטית
```

`npm run typecheck` מריץ `tsc --noEmit` על הפונקציות.

Netlify מקצה מסד נתונים אוטומטית — אין מה ליצור ידנית ואין connection string
לנהל. כל ענף preview מקבל ענף DB מבודד משלו עם עותק של נתוני הפרודקשן.

## תלויות

Leaflet 1.9.4 מסופק מקומית תחת `assets/vendor/` — אין תלות ב-CDN.
הפונט (Heebo) נטען מ-Google Fonts ונופל בחן לפונט מערכת אם אינו זמין.
אריחי המפה מגיעים מ-OpenStreetMap ודורשים חיבור לאינטרנט; אם המפה
אינה נטענת, האתר ממשיך לעבוד ומציג הודעה מתאימה, ובכל יום יש קישור
ניווט ל-Google Maps.
