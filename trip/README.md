## לשונית ההוצאות

משחזרת את הלוגיקה של גיליון ההוצאות מהטיול הקודם:

- **הזנה במטבע המקורי** — £ / € / $ / ₪, עם המרה אוטומטית לשקל.
- **שערי המרה ניתנים לעריכה** — שינוי שער מחשב מחדש את כל הטבלה מיידית.
- **11 סעיפי הוצאה** — אוכל, דלק, לינה, טיסות, נסיעות, אטרקציות, חניה,
  קניות, בילויים, רפואה, אחר.
- **קיזוז בין זוגות** — חלוקה שוויונית לנפש, ואז חישוב ההעברה הנדרשת
  ("זוג 2 מעביר X ₪ לזוג 1"). האלגוריתם חמדני ותומך גם ביותר משני זוגות.
- **ניתוחים** — חלוקה לסעיפים, הוצאה לפי אדם, והוצאה יומית לאורך הטיול.
- **תקציב יעד** — אופציונלי, עם מד ניצול שמשנה צבע בחריגה.
- **ייצוא/ייבוא CSV** — עם BOM כדי ש-Excel יציג עברית תקינה. הייבוא מקבל
  תאריכים בפורמט `yyyy-mm-dd` או `dd/mm/yyyy`.

### עריכת המסלול

כל התוכן יושב ב-`assets/js/data.js` במבנה אחד (`TRIP`). כדי לשנות יום —
עורכים את האובייקט שלו; אין צורך לגעת ב-HTML או ב-JS. שדות מרכזיים לכל יום:

```js
{
  n: 5, date: "2026-09-01", dow: "שלישי",
  title: "...", region: "היילנדס",   // region מזין את סינון המפה ואת גרף הק"מ
  mode: "drive",                      // flight | train | drive | city
  drive: { km: 70, hours: 1.5, note: "..." },
  hotel: { name: "...", area: "...", lat, lng, booked: true },
  plan:  [{ time: "09:00", text: "..." }],
  tips:  ["..."],
  points: [{ name: "...", lat, lng, type: "hike" }],  // type קובע את האייקון
  path:  [[lat, lng], ...],           // הקו על המפה
  pathMode: "drive"
}
```

## תלויות

Leaflet 1.9.4 מסופק מקומית תחת `assets/vendor/` — אין תלות ב-CDN.
הפונט (Heebo) נטען מ-Google Fonts ונופל בחן לפונט מערכת אם אינו זמין.
אריחי המפה מגיעים מ-OpenStreetMap ודורשים חיבור לאינטרנט; אם המפה
אינה נטענת, האתר ממשיך לעבוד ומציג הודעה מתאימה, ובכל יום יש קישור
ניווט ל-Google Maps.
