    📬 ייבוא מהמייל

    כדי לקרוא מה-Gmail צריך Client ID משלכם. אין כאן מפתח משותף: Google מזהה את האפליקציה מול החשבון שיצר אותה, וכך גם הגישה נשארת שלכם בלבד. ההרשאה המבוקשת היא קריאה בלבד.

    1. נכנסים ל-Google Cloud ויוצרים פרויקט.
    2. APIs & Services ← Library ← מפעילים Gmail API.
    3. OAuth consent screen ← External ← מוסיפים את עצמכם ב-Test users.
    4. Credentials ← Create credentials ← OAuth client ID ← Web application.
    5. ב-Authorized JavaScript origins מוסיפים את כתובת האתר הזה.
    6. מעתיקים את ה-Client ID לכאן.

    המיילים נקראים בדפדפן מול Google ואינם עוברים דרך השרת. מסמך שנבחר נשלח לעוזר — הוא קורא, מציע, והשמירה במכשיר קורית רק באישור.
